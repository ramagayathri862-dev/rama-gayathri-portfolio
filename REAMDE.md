# Rama Gayathri.G — Developer Portfolio

A responsive single-page developer portfolio built using:

- HTML
- CSS
- JavaScript

The portfolio uses a modern developer/code-editor inspired design with:

- Responsive layout
- Dark/light mode
- Mobile navigation
- Project filtering
- Scroll animations
- Typing animation
- Skills progress bars
- Education timeline
- Certification section
- Contact form
- GitHub and LinkedIn links
